# Veritas Playbook Repos

**Practical workflows and systems for knowledge workers**

This is my playbook: a collection of guides, workflows, examples, and templates that I've built and refined over time, mostly around using Artificial Intelligence (AI) effectively. I'll be adding content as questions come up and sharing what actually works.
