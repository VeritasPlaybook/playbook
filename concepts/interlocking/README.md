# Interlocking

**Read the page:** [Interlocking: how AI agents working for different teams can share without colliding](https://veritasplaybook.github.io/playbook/concepts/interlocking/)

This folder holds the source for a standalone page. GitHub shows `index.html` as code; the link above opens it as the page.

**What it covers:** Anthropic's November 2026 "Worse Together" study found that when each person's AI agent shares one resource with other people's agents, the group does worse than one agent serving everyone. The page looks at why, what other researchers found, how to structure coordination in a large organization, what history and today's protocols already solve, what companies and regulators are doing, and a proposed design borrowed from railway interlocking: each team's agent acts for its team, inside a small set of rules that are enforced, not trusted.
