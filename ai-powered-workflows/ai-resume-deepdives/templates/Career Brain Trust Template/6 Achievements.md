# 6. Achievements

This is the deduplicated headline-metrics file. Big numbers, by employer, with source attribution. Your resume-builder skill pulls metrics from here when a bullet calls for a specific figure.

Two rules to keep this file useful:

1. **Numbers belong in only one place.** If a metric appears here, it should not contradict the same metric inside the Experience file. If you discover a conflict, fix this file first, then update the Experience file.
2. **Cite the source.** Every metric has a source attribution: an internal report, a public press release, an offer letter, a dashboard screenshot. If you cannot point to where the number came from, it does not belong here.
