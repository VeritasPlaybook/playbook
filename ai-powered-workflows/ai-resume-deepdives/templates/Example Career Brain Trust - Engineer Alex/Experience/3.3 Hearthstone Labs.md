### 3.3 Hearthstone Labs, Software Engineer

**Dates:** September 2019 to February 2021
**Location:** Portland, Oregon
**Tags:** `#Engineering` `#Backend` `#Python` `#FastAPI` `#0to1` `#Startup` `#CICD` `#Foundational`
**Source priority:** LinkedIn profile (canonical, May 2026). First engineering role post-graduation; the company grew from 4 to 14 employees during my tenure.

---

#### Canonical Bullets

- Built the core Representational State Transfer (REST) Application Programming Interface (API) in Python (FastAPI) supporting the company's first 5,000 customers from closed beta through general availability.
- Designed and shipped the Continuous Integration and Continuous Deployment (CI/CD) pipeline using GitHub Actions; cut average deploy time from 23 minutes to 4 minutes.
- Owned the database migration tooling; built reusable migration primitives that the team still uses as of 2026 (5 years post-departure).
- Onboarded 3 incoming engineers during the company's growth from 4 to 14 employees; wrote the initial onboarding documentation that survived through Series A.
- Set up the application monitoring stack (Datadog plus PagerDuty) from scratch; defined the first set of Service Level Objectives (SLOs) for the production service.
